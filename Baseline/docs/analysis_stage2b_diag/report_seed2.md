# seed2 折为什么提升小（任务39）

数据：`diag_target.py` 对每折按折重训的 Stage2B 跑一遍（`data/diag_loro_<fold>.csv`，只取该折的测试 run），
再接上 GT 占用 beam 头的命中；脚本 `diag_seed2.py`，输出 `diag_seed2.txt`。

## 结论

**seed2 的差距几乎全部来自 Stage2B 在 TX_CAR1 不在前方时找不到它。beam 头本身没有问题。**

- seed2 里 GT 和新 pred 差 16.9 点。其中 16.6 点来自 206 个 TX_CAR1 样本（占 TX_CAR1 的 37%），
  这些样本预测的 target IoU≈0：GT 头命中 99.5%，pred 头只有 10.2%。
- 这 206 个里，109 个预测为空；另外 97 个预测出一个块，但**全部在接收车正前方约 20 m**，
  离真实 TX_CAR1 的中位距离是 25 m，也不在 TX_CAR2 上。
  真实位置：后方 121 个，左侧 53 个，右侧 14 个，前方 18 个。
- 当占用预测对的时候（IoU>0.6，238 个），pred 头和 GT 头几乎一样（92.4% vs 93.7%）。

## 原因：训练数据里 TX_CAR1 几乎总在前方

TX_CAR1 相对接收车的方位占比：

| run | 前 | 后 | 左侧 | 右侧 |
|---|---|---|---|---|
| legacy | .95 | 0 | 0 | .02 |
| seed1 | .89 | 0 | 0 | 0 |
| **seed2** | **.57** | **.22** | **.10** | .11 |
| seed3 | .91 | 0 | 0 | .05 |
| seed4 | .93 | 0 | 0 | .02 |
| seed5 | .72 | .10 | 0 | .15 |

seed2 折的训练集里，只有 seed5 有少量"TX_CAR1 在后方"的样本，而"TX_CAR1 在左侧"一个都没有。
所以 target 分支对角色 0（TX_CAR1）学到的是"在前方找"这个位置先验，也就是任务36 里说的位置捷径。
新数据里 TX_CAR2 前后左右都出现过，把角色 1 的捷径打破了，但角色 0 的还没打破。
TX_CAR1 一跑到后方或左侧，模型就要么输出空，要么在前方凭空画一辆车。

时间上，错误集中在 seed2 中段（sid ≈ 2209–2415）。这段里 TX_CAR1 在接收车后方、侧后方 5–12 m。
seed2 最后一段（sid ≥ 2485）GT 头也只有 23%，属于本身就难，和占用无关。

seed2 的 TX_CAR2 IoU 也偏低（.42，质心误差 1.9 m），但它的面板一直是前后方向，beam 没受影响。

## 下一步可选

- 数据层面：采集或加入 TX_CAR1 在后方、侧方的场景，或者在训练里交换两辆车的角色，
  让角色 0 也见到各个方位。这是根本办法。
- 模型层面：让 target 分支更依赖外观、不依赖位置。比如训练时随机交换 TX_CAR1/TX_CAR2 的角色标签和对应 GT，
  前提是角色输入能对应到可见的外观差异。
