## 2. 原因：Stage2B 的训练数据里根本没有这类目标

- Stage2B 只用 legacy sid 2–626 训练。这部分数据里，目标方位 **0% 在侧方（30–150°）**，49% 在正前方、51% 在正后方，只有 **2.9% 距离在 10 m 以内**。
- 新的 5 个 run 里，侧方目标占 15–25%，10 m 以内占 19–43%。
- 对侧方目标，预测的 target 质心中位数在 (0.2, −0.0) m，**54% 落在本车 3 m 以内**，而 GT 一个都没有。也就是说，Stage2B 在目标位于侧方时，把**本车自己**标成了 target。
- 30–40 m：一半的样本预测出多个块，最大块和 GT 相差中位数 25 m，像是标到了别的车上。
- 对见过的场景泛化也很差：legacy 训练帧 IoU .95，legacy 没见过的帧 .68，seed1–5 只有 .24–.29。

## 3. 结论

预测输入比 GT 损失的 14–18 个点，主要来自 **Stage2B 没见过侧方和近距离目标**（训练集分布覆盖不到），不是 beam head 的问题。改进 beam head 补不回来。最直接的办法是**用包含侧方和近距离目标的数据重训 Stage2B**。
