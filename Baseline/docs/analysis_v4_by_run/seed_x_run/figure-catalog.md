# Figure Catalog（run × 种子）

所有图由 `plot_seed_figures.py` 从 `data/*.csv` 生成，每张图都有 PDF 和 PNG 两个版本。图 1–3 是单种子分析的结果，见上一级目录的 `figure-catalog.md`。

## figure-04-per-run-by-seed

- Purpose：主图。四个主要组合在每个 run 上的准确率，同时显示每个训练种子，用来区分训练噪声和场景差异。
- 数据来源：`data/seed_long.csv`（metric = panel_pair）。
- 绘制变量：灰点 = 一个训练种子；蓝色短横线 = 3 个种子的均值；橙色短线 = 该 run 的 majority 基线。
- Caption 必须说明：每组 3 次训练（s0 未固定种子，s1/s2 固定种子）；val = 每个 run 的时间尾段；best.pth 按同一个 val 选出。
- 关键观察：大多数格子里 3 个点挤在 ±5 点以内，run 之间却相差 30–60 点；gt/scene_target 在 seed2 上是例外（.29–.59）。
- 解读检查：(1) 为什么有这张图：判断方差主要来自场景还是训练。(2) 应该注意到：竖向的点很集中，横向的跨度很大。(3) 改变了什么：应该增加独立的 run，而不是增加种子。
- 已知限制：每个 run 的 val 只有 220–314 行，而且由少数事件主导。

## figure-05-seed-mean-contrasts

- Purpose：7 个主对比的森林图（3 种子均值，按 run 配对）。
- 数据来源：`data/seed_contrasts.csv`。
- 绘制变量：灰点 = 每个 run 的差值；蓝色 ◆ + 横线 = 均值 ± 95% t-CI；绿色线 = 两层自助法 95% 区间；右侧文字 = 正的 run 数、置换 p、Holm(t)。
- Caption 必须说明：n = 6 个 run；两层自助法在 run 很少时会低估方差；Holm 族的大小是 7。
- 关键观察：Q1 和 Q7 的区间远离 0；Q2 的点多数在 0 左侧；Q4 的点分布在 0 两侧。
- 解读检查：(1) 为什么有这张图：确认哪些结论在加入种子以后仍然站得住。(2) 应该注意到：Q2 从单种子时的“≈0”变成了偏负。(3) 改变了什么：预测 scene 的措辞改成“没有帮助，偏向变差”；Q4 改成优化问题，不再作为信息量上的结论。
- 已知限制：t-CI 依赖正态近似。

## figure-06-power-vs-runs

- Purpose：给新实验定规模。3 个种子时，功效随 run 数的变化。
- 数据来源：`power_plan.py`，用 statsmodels 的 TTestPower 算公式解，再用 skill 的蒙特卡洛框架核对。
- 绘制变量：x = 独立 run 数；y = 功效（配对 t，α = .05）；三条线对应 τ = .065/.10/.14；虚线 = 80%；点线 = 现在的 6 个 run。
- Caption 必须说明：σ_s = .05；τ 来自 6 个 run 的估计，不确定性很大；数值来自公式解，蒙特卡洛核对结果见 stats-appendix §4。
- 关键观察：检测 10 点的差异需要约 7–19 个 run，检测 5 点的差异需要约 21–69 个 run；现在 6 个 run 时，检测 10 点差异的功效只有 .28–.72。
- 解读检查：(1) 为什么有这张图：回答“要补多少数据”。(2) 应该注意到：τ 越大，需要的 run 越多，而且增长很快。(3) 改变了什么：下一步的数据采集目标定为 ≥ 20 个 run。
- 已知限制：模型假设正态，并假设 run 来自同一个生成过程。
