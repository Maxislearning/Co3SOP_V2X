## 1. 设计

| 层级 | 角色 | 数量 |
|---|---|---|
| source run | 分析单位（独立重复）；同一 run 上评估全部组合 → 以 run 为区组 | 6 |
| 训练种子 | 模型的技术重复；先在 run 内取均值 | 每组 3（s0/s1/s2） |
| 事件 / 连续帧 / 链路 | run 内的子样本，不作为独立样本 | — |

种子编号在不同组合之间**不配对**（gt_target 的 s1 与 gt_scene_target 的 s1 是两次互不相关的训练），因此对比方式是：每个 run 先对 3 个种子取均值，再按 run 配对。

## 3. 推断检验

方法：每个 run 先取 3 种子均值，再算配对差 d_r，n = 6。
- 主检验：精确符号翻转置换（64 种翻转，最小 p = 0.031）。
- 辅助检验：配对 t（df = 5）。
- 两种 p 值各自在 7 个对比的族内做 Holm 校正。
- 区间：t-CI，以及两层自助法区间（先重抽 run，再在每个组合内独立重抽种子，10 000 次）。
- `frac cells>0`：所有“A 的某个种子 × B 的某个种子 × run”的格子中，差值为正的比例。

## 4. 功效分析（statistical-power skill，`power_plan.py`）

模型：d_r = Δ + u_r + (ē_A − ē_B)。u_r ~ N(0, τ²) 是场景和处理的交互；ē ~ N(0, σ_s²/k)，σ_s = 0.05（run 内种子 SD 的典型值），k 为每组种子数。
τ 按观测到的 run 间差异 SD 扣掉种子噪声得到：Q2 约 0.065，Q3/Q4 约 0.14；外加 0.10 作为中间档。所有估计都来自 6 个 run（df = 5），τ 本身的 95% 区间大约是估计值的 ×0.6 到 ×2.5，所以做三档敏感性分析。
检验：run 级配对 t（与实际分析相同）。公式计算结果用 skill 的蒙特卡洛框架核对过（4000 次/格）：
- Δ = 0、τ = .10、k = 3、n = 20 时，误报率 0.053 [0.046, 0.060]；
- Δ = .05、τ = .10、k = 3 时，公式算出 39 个 run 可达 80% 功效，模拟得到 n = 36 时功效为 0.772；
- Δ = .10、τ = .14、k = 3 时，公式算出 19 个 run，模拟得到 n = 18 时功效为 0.791。

**80% 功效所需的 run 数**

| α | Δ | τ | k = 1 | k = 3 | k = 5 |
|---|---|---|---|---|---|
| .05 | 5 点 | .065 | 31 | 21 | 19 |
| .05 | 5 点 | .10 | 50 | 39 | 37 |
| .05 | 5 点 | .14 | 80 | 69 | 67 |
| .05 | 10 点 | .065 | 10 | 7 | 7 |
| .05 | 10 点 | .10 | 14 | 12 | 11 |
| .05 | 10 点 | .14 | 22 | 19 | 19 |
| .0167（3 个主对比 Bonferroni） | 10 点 | .10 | 19 | 16 | 15 |
| .0167 | 10 点 | .14 | 29 | 26 | 25 |

**现有 6 个 run 的功效（α = .05）**
- Δ = 10 点：k = 3 时为 .28–.72，k = 5 时为 .29–.77；
- Δ = 5 点：k = 3 时为 .11–.26。

所以 Q2/Q4 的“不显著”**不能**解读为“没有差异”。

种子从 3 个加到 5 个，所需 run 数最多只少 2–4 个；run 数才是决定因素。

## 5. 限制

1. n = 6 时，置换检验做 Holm 校正后不可能低于 0.22；只有 Q1、Q7 在 t 检验的正态假设下能通过校正。
2. val 同时用于选 best epoch 和报告结果，所有数字都偏乐观，而且对不同组合的偏差大小不一定一样（坍缩组选在第 1 个 epoch）。
3. val 是每个 run 的时间尾段，NLOS 和部分 L/R 事件几乎只出现在 val 中，测的是同一 run 内向后外推，不是跨场景泛化。
4. τ 和 σ_s 只从 6 个 run、3 个种子估计，功效表要按敏感性范围来读。
5. 功效分析假设新 run 和现有 run 来自同一个生成过程，构成同样不平衡。新设计如果每个 run 的测试样本更多（见报告的修改方案），τ 里由抽样带来的那部分会变小，需要的 run 数也可能更少。
