## 1. 分析单位与设计

| 项 | 内容 |
|---|---|
| 分析单位 | source run（`sample_id // 1000`）：legacy(0)、seed1..seed5(1..5)，**n = 6** |
| 每个 run 的 val 行数 | 314 / 256 / 220 / 240 / 256 / 242（=采样点×2 条链路 TX_CAR1/TX_CAR2） |
| val 的构成 | 每个 run 按 sample_id 排序后**最后 20%**，与 train 末尾紧邻（train_max+1 = val_min，6/6 个 run） |
| 训练重复 | 每组只有 **1 个训练种子**；6 个 run 是同一个模型在 6 个子集上的评估，不是 6 次独立训练 |
| 主指标（预先指定） | **面板对准确率** panel_pair = TX 面板与 RX 面板都对（Top1 预测的 idx//16） |
| 次指标 | TX/RX 面板准确率、TX/RX Top1/Top5、联合 beam 对 Top1/Top10 |
| 基线 | majority：train 中最常见的 (TX面板, RX面板) 组合；prior：train 标签频率先验（与 `rerank_prior.py` 相同） |

为什么不用行做单位：同一 run 内 10Hz 连续帧高度自相关，同一采样点的两条链路共用 scene 输入；LEFT/RIGHT 和 NLOS 行在每个 run 内只来自 0–3 个连续事件（见 §2）。把 1528 行当独立样本会大幅低估方差。

## 4. 推断检验

**检验方法**（每个对比都是同一 run 上两个模型的配对差，n = 6）：
- 主检验：**精确符号翻转置换检验**（2⁶ = 64 种翻转，双侧）。不做分布假设。n = 6 时可能的最小 p = 1/32 = 0.031。
- 辅助：配对 t 检验（df = 5）、Wilcoxon 符号秩（精确）；对差值做 Shapiro–Wilk（n = 6 时检验力很低，仅作参考）。
- 效应量：均值差（百分点）、Cohen's d_z = mean(d)/SD(d)、差值为正的 run 数、留一 run（LOO）均值范围。
- 多重比较：主族 7 个对比，用 **Holm** 校正。
- 对照：pooled 行级 McNemar（精确二项）p，**仅用于展示忽略聚类会造成多大偏差，不作为证据**。

## 5. 假设检查与局限

1. **结构性检验力上限**：n = 6 时精确置换检验最小 p = 0.031；在 7 个对比的族内做 Holm 后，**任何对比都不可能低于 0.22**。所以“无分布假设 + 多重校正后显著”从设计上就不可能达到。只有加上 t 检验的正态假设，Q1 和 Q7 才能通过校正。
2. **单一训练种子**：run 间方差只反映数据/场景异质性，不包含训练随机性。“模型 A 比 B 好”的结论依赖于这一次具体的训练结果。
3. **val = 每个 run 的时间尾段**，与 train 末尾紧邻，边界附近存在时间相关；同时 val 的场景分布与 train 不同（NLOS 和部分 L/R 事件几乎只出现在 val 中）。
4. **run 构成高度不均**：seed4 的 val 没有 L/R、majority 准确率 0.996（接近退化）；seed5 的 majority 只有 0.029。涉及 majority 的对比（Q5/Q6）主要由构成决定。
5. **事件数极少**：L/R 共 7 个事件、NLOS 共 6 个事件，任何少数类结论都只是事件级别的轶事证据。
6. **主族的选取**是本次分析时定义的（参照任务30/32 记录中已有的问题），不是在看到数据之前预注册的。
